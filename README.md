# PickMe 抽奖系统使用指南

## 🎯 功能介绍

PickMe 是一个基于 Python 开发的桌面抽奖程序，适用于年会抽奖、活动选人等场景。

### 核心功能

- ✅ **参与者管理** - 批量导入、手动添加参与者
- ✅ **奖项设置** - 自定义奖项名称、人数和颜色
- ✅ **酷炫动画** - 科技风姓名滚动 + 粒子特效 + 烟花效果
- ✅ **公平抽奖** - 随机算法，防重复抽取
- ✅ **结果管理** - 中奖名单展示与导出

---

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行程序

```bash
python main.py
```

## 📖 使用步骤

### 步骤1: 添加参与者

进入【参与者管理】选项卡：

**方式一：手动添加**
- 输入姓名和部门（可选）
- 点击"添加"按钮

**方式二：批量导入**
- 准备一个 .txt 文件，每行一个姓名
- 点击"从文件导入"按钮
- 选择文件即可批量导入

### 步骤2: 设置奖项

进入【奖项设置】选项卡：

- 点击"添加奖项"
- 输入奖项名称（如：特等奖）
- 输入中奖人数
- 选择奖项颜色
- 点击"添加奖项"完成

### 步骤3: 开始抽奖

进入【抽奖】选项卡：

1. 点击"刷新"更新奖项列表
2. 在下拉菜单中选择要抽取的奖项
3. 点击"🎰 开始抽奖"按钮
4. 看到姓名快速滚动 + 粒子特效
5. 点击"⏹ 停止抽奖"按钮
6. 系统自动抽取幸运儿，触发烟花效果！

### 步骤4: 查看结果

进入【中奖名单】选项卡：

- 查看按奖项分组的中奖名单
- 显示中奖者姓名和抽奖时间
- 点击"导出名单"保存结果
- 点击"清空结果"重新开始

## 🎨 特色功能

### 酷炫科技风界面

- 深色主题 + 霓虹光效
- 粒子动画背景
- 姓名滚动时随机颜色变换
- 中奖时触发烟花爆炸效果

### 公平抽奖机制

- Python random 随机算法
- 已中奖者自动排除，不重复抽取
- 实时统计剩余人数

### 数据本地存储

- 数据自动保存到 `data/` 目录
- JSON 格式存储，易于备份
- 支持导出为文本文件

## 🔧 常见问题

**Q: 如何打包为 exe 文件？**
```bash
pip install pyinstaller
pyinstaller --onefile --windowed main.py
```

**Q: 抽奖后如何重新开始？**
- 进入"中奖名单"选项卡
- 点击"清空结果"按钮
- 即可重新抽奖

**Q: 如何导出参与者名单？**
- 进入"参与者管理"选项卡
- 点击"导出名单"按钮

**Q: 数据存储在哪里？**
- 所有数据保存在 `data/` 目录下的 JSON 文件中
